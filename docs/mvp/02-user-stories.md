# MVP User Stories (Implemented + Pending)

## Implemented Stories

### Dashboard and Valuation
- As an Investment Manager, I want a dashboard with total value, invested value, and returns so that I can track portfolio health quickly.
- As an Investment Manager, I want asset allocation percentages by Stocks, Bonds, and Crypto so that I can monitor diversification.
- As an Investment Manager, I want positive and negative P/L to be visually distinct so that I can detect risk quickly.

### Holdings and Transactions
- As an Investment Manager, I want to add holdings for stocks, bonds, and crypto so that I can maintain a multi-asset portfolio.
- As an Investment Manager, I want to sell holdings from the holdings table so that portfolio positions remain current.
- As an Investment Manager, I want transaction history recorded and shown in a table so that I have an audit trail.
- As an Investment Manager, I want holdings filters by type so that I can focus on one asset class at a time.

### Marketplace and Buy Flow
- As an Investment Manager, I want a marketplace with Stock, Bond, and Crypto categories so that I can explore instruments by type.
- As an Investment Manager, I want to click Buy on a marketplace stock and land on a prefilled Add Asset form so that trade entry is faster and less error-prone.
- As an Investment Manager, I want to click Buy Bond on marketplace bonds and get a prefilled bond form so that I can add fixed-income positions quickly.

### Stock Insights and Theme
- As an Investment Manager, I want stock-level transaction details and recent performance charts so that I can evaluate a symbol before making decisions.
- As an Investment Manager, I want stock fields auto-filled from symbol lookup so that I enter less manual data.
- As an Investment Manager, I want light/dark mode with persisted preference so that I can work comfortably.

## Partial / In Progress Stories

### Portfolio and Asset CRUD Completeness
- As an Investment Manager, I want full portfolio management in the primary UI so that I can create and switch portfolios without backend-only workflows.
- As an Investment Manager, I want to edit existing holdings so that I can correct quantity/price/rate mistakes without deleting and re-adding.

### Market and Analytics Depth
- As an Investment Manager, I want live pricing for all asset classes so that valuation is current across stocks, crypto, and bonds.
- As an Investment Manager, I want performance charts based on historical portfolio valuation so that trend analysis reflects true NAV movement.

### Settings Persistence
- As an Investment Manager, I want settings actions (profile, preferences, security) saved server-side so that my configuration is durable across devices.

## Yet to Implement Stories

### Alerts and Warnings
- As an Investment Manager, I want automatic alerts for drawdown, concentration, and stale prices so that I can react quickly to risk.
- As an Investment Manager, I want alert severity and read/unread status so that I can prioritize actions.

### AI Analysis
- As an Investment Manager, I want AI analysis restricted to owned stocks so that insights are directly relevant to my portfolio.
- As an Investment Manager, I want AI outputs to explain rationale and confidence so that I can trust recommendations.
